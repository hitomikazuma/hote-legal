ホート（HOTE）利用規約

制定日：2026年9月30日
最終更新日：2026年10月27日
運営者：hitomikazuma

この利用規約（以下「本規約」）は、運営者 hitomikazuma（以下「運営者」）が提供するモバイルアプリ「ホート」（英語表記：HOTE。以下「本アプリ」）の利用条件を定めるものです。本アプリを利用する方（以下「ユーザー」）は、本規約に同意したうえで本アプリを利用するものとします。

第1条（サービスの内容）

本アプリは、ユーザーが自分の宿泊を記録し、時系列で見返すための iOS / Android 向けアプリです。次の機能を提供します。

  • 宿泊記録（ホテル名、チェックイン日、チェックアウト日、料金、5段階評価、メモ、場所メモ）の登録・閲覧・更新・削除
  • 宿泊記録への写真の添付
  • 月額のサブスクリプション（以下「プレミアム」）による、1件の宿泊に付けられる写真の枚数の拡大

無料で利用する場合とプレミアムの場合の違いは、1件の宿泊に付けられる写真の枚数です。宿泊記録の件数に制限はありません。

本アプリの v1.0 では、ユーザーの宿泊記録と写真を、他のユーザーや第三者に公開・共有する機能を提供しません。

第2条（アカウント）

  1. 本アプリを利用するには、メールアドレスでログインする必要があります。ログインは、メールアドレス宛に送信される6桁のコードを入力して行います。
  2. ユーザーは、自分が利用できる正確なメールアドレスを使い、そのメールアドレスとログイン用のコードを自己の責任で管理するものとします。
  3. ユーザーは、アカウントを第三者に利用させたり、譲渡・貸与したりしてはなりません。
  4. ユーザーは、本アプリの設定画面からいつでもアカウントを削除できます。削除の内容は、第3条第5項のとおりです。

第3条（ユーザーの記録の取り扱い）

  1. ユーザーが本アプリに登録した宿泊記録・写真（以下「ユーザーの記録」）に関する権利は、ユーザーに帰属します。
  2. 運営者は、本アプリの提供に必要な範囲で、ユーザーの記録を保存・処理します。
  3. ユーザーの記録は、ユーザー本人のみが閲覧・編集できるよう管理されます。v1.0 では、ユーザーの記録を外部に公開・共有しません。
  4. 個人情報の取り扱いの詳細は、別に定めるプライバシーポリシーによります。
  5. ユーザーがアカウントを削除すると、本人の宿泊記録、写真メタデータ、保存された写真、ログイン用のアカウントが直ちに物理的に削除されます。削除後の復旧はできません。

第4条（月額購読）

  1. プレミアムは、月額300円の自動更新サブスクリプションです。製品 ID は hote_premium_monthly です。年額プランおよび買い切りの提供はありません。
  2. プレミアムの決済は、Apple の App Store を通じて行われます。購入状態の判定には RevenueCat のサービスを利用します。
  3. サブスクリプションは、現在の期間が終了する少なくとも24時間前までに解約しない限り、自動的に更新され、同額が請求されます。
  4. 解約および返金の手続きは、ユーザーご自身が、お使いの端末の App Store のサブスクリプション管理から行うものとします。
  5. 本アプリ内でのアカウント削除は、宿泊記録・写真・ログイン用アカウントを削除するものであり、App Store のサブスクリプションの解約にはなりません。アカウント削除にともなって、ストア側の解約や返金が行われることもありません。課金を止めたい場合は、App Store のサブスクリプション管理で解約してください。
  6. 購入済みのプレミアムは、本アプリから購入の復元を行えます。

第5条（禁止事項）

ユーザーは、本アプリの利用にあたり、次の行為をしてはなりません。

  • 法令または公序良俗に違反する行為
  • 他人の権利（著作権、肖像権、プライバシーその他の権利）を侵害する写真や情報を登録する行為
  • 本アプリまたは本アプリの提供に用いられるサーバー・ネットワークに過度な負荷をかけ、運営を妨げる行為
